- **Conda package downloads answer conditional requests with `304 Not Modified`, and the hosted package route reads the database once** (#4579, #4181). Package responses ignored `If-None-Match` and `If-Modified-Since` and carried no `ETag` or `Last-Modified`, so an artifact manager in front of Artifact Keeper that revalidates its cache (Nexus, for example) re-downloaded every package on each refresh. Every package response now carries `ETag: "<sha256>"` and `Last-Modified`, and a matching validator is answered `304` with no body on hosted channels, cached Remote channels and Virtual channels (served by a hosted member or by a cached Remote member), under the plain and both `/t/<token>/` URL layouts. Access, quarantine and scan-policy checks still run first, so a held or blocked package is refused rather than revalidated. A Remote package that is not yet in the proxy cache keeps the upstream's `ETag` and is always served in full, so a conditional request never cancels a cache fill. The hosted package route also resolves the repository, its visibility, the artifact, its quarantine state and whether a scan policy applies in one statement instead of five sequential round trips, which matters for fleets of installers fetching thousands of packages each.
