- **The backend image's bundled `grype` moves to upstream v0.120.1, which pins `golang.org/x/crypto` v0.57.0 and `google.golang.org/grpc` v1.83.2 itself** (#3698). `golang.org/x/crypto` below v0.56.0 carries CVE-2026-56855 and CVE-2026-78662 (`x/crypto/ssh` denial of service). Trivy still rates both UNKNOWN, so they had not failed Docker Publish's `CRITICAL,HIGH` gate. The 1.11.0 `x/net` override already moved `x/crypto` to v0.57.0, but only as a side effect. With this release that version comes from upstream's own `go.mod`, and the build now fails if the compiled binary's Go build info records `x/crypto` below v0.56.0. The source pin moves from v0.118.0 to **v0.120.1** (commit `6f8d854a`) in `docker/Dockerfile.backend{,.alpine}`. Because v0.120.1 pins grpc v1.83.2, the gRPC override from #3655 and #3790 has reached its removal condition and is deleted. The `golang.org/x/net` v0.60.0 override for CVE-2026-78669 stays, because v0.120.1 still pins v0.59.0. It now starts from v0.59.0 and moves exactly one module. The five `github.com/docker/docker` entries in `.trivyignore` stay live: v0.120.1 still pins v28.5.2, and an override to v29.3.1 still fails to resolve. `grype --version` now prints `0.120.1`. The image is still built on go1.27.2 or newer.
