- **A Debian repository imported before 1.11.2 can recover its package registrations without the source system** (#4740). Re-running the migration job was the only documented repair for a repository whose `.deb` rows had no `debian` control document, catalog entry, or maintainer-script analysis, which needs access to the source. A new admin backfill, `POST /api/v1/admin/repositories/{key}/backfill-debian`, walks the live `.deb` rows that lack that metadata, reads each `control.tar` member from the repository's own storage with bounded ranged requests, and records the same control document, catalog row, and script analysis a native upload writes. A package outside `pool/<component>/` (a flat `pool/<file>.deb`, or the `pool/<letter>/<name>/` layout of a Nexus apt repository or an Ubuntu pool mirror) is moved under `pool/main/`, the component the migration importer picks without the source's `deb.component`. It also soft-deletes the migration-origin `dists/` index copies from the artifact list, since AK renders and signs its own, while leaving hosted rows alone. The run is idempotent and bounded per call (a truncated call returns `next_after` to pass as `after` on the next), and reports unreadable or inconsistent packages without aborting the rest.
