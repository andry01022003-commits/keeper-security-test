- **NuGet repositories translating a V2 upstream now list the versions on every page of the upstream feed** (#4856). A Remote over a V2 OData feed answers its V3 registration index and flat-container version list from the feed's `FindPackagesById()`, and a virtual repository merges a V2 member the same way into its registration, flat container and V2 feed. Only the first page of that feed was read: the feed-level `<link rel="next">` continuation (with its `$skiptoken`) was ignored, so every version the upstream served on a later page was missing and restores that needed one failed. The continuation is now followed, up to 20 pages per query, with rows repeated across pages listed once. A continuation must stay on the configured upstream origin (scheme, host and port), the only place the repository's upstream credentials are sent; one that points elsewhere is not requested, a warning is logged, and the pages already read are served. Continuation pages are cached per URL next to the first page. The raw V2 feed of a Remote was not affected: its next link is rewritten onto AK and the client follows it. Contributed by @PauloHMattos.
