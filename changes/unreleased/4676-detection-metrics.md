- **`/metrics` now exports connection, rate-limit, SSRF, rejected-credential and proxy-scan series, and labels OCI requests with route templates** (#4676). New series: `ak_http_connections_open` (accepted connections still open, idle keep-alive and half-sent heads included); `ak_rate_limit_rejections_total{limiter}` for every 429 a limiter answers (`login`, `token`, `login_global`, `auth`, `api`, `search`, `presign`, `password_change`, `upload`, `proxy_rescan`), where a refused login previously left no metric, audit row or log line; `ak_ssrf_blocks_total{surface}` (`upstream`, `webhook`, `sso`, `ldap`, `plugin`, `peer`, `internal`), including connect-time DNS refusals; `ak_auth_failures_total{surface,reason}` for each presented credential that is rejected on the login form, API tokens and JWTs, HTTP Basic, `/v2/token`, the CI OIDC exchange and SSO, with `reason` bucketed to `bad_password`, `unknown_user`, `lockout`, `expired`, `invalid_token` or `scope` and never a username or token; and `ak_proxy_scan_verdicts_total{verdict,action}` for each pull through the scan-on-proxy gate. Requests to the OCI distribution API (`/v2/<name>/manifests/<reference>` and the rest) were all labelled `path="unmatched"` in the `ak_http_*` series; they now carry the spec's route template, such as `/v2/{name}/manifests/{reference}`, so repository names, tags and digests never become label values. No setting changes. `ak_storage_used_bytes` gains no `repository` label: there is no per-repository storage gauge to attach it to. The series, their labels and a note that counters restart from zero with the process (query them with `increase()`) are in `docs/operations/detection-metrics.md`.
